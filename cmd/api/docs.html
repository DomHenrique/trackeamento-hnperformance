Instalação Básica da Tag no Site

Adicione a tag do script preferencialmente dentro da tag <head> ou logo antes do fechamento de </body> do site cliente. O script é ultraleve (< 4KB) e assíncrono (async), sem nenhum impacto no tempo de carregamento da página.

HTML 
<!-- HN Performance Server-Side Tracking SDK -->
<script 
  src="https://trackeamento.hnperformancedigital.com.br/sdk/tracker.js" 
  data-site-key="hn_site_9k8m2x7v1b3n4p6q8r0s" 
  async>
</script>
Como instalar no Google Tag Manager:
  1. No painel do GTM, vá em Tags → Nova.
  2. Em Configuração da Tag, selecione HTML Personalizado.
  3. Cole o código abaixo no campo HTML.
  4. Em Acionamento, selecione Initialization - All Pages (ou All Pages).
  5. Clique em Salvar e depois em Publicar.
HTML Personalizado no GTM 
<script 
  src="https://trackeamento.hnperformancedigital.com.br/sdk/tracker.js" 
  data-site-key="hn_site_9k8m2x7v1b3n4p6q8r0s" 
  async>
</script>
Opções de instalação no WordPress:
  • Elementor Pro: Vá em Elementor → Custom Code → Adicionar Novo → Localização: <head> → Cole o script.
  • Via Plugin Gratuito: Instale o plugin "WPCode (Insert Headers and Footers)" e cole no bloco Header.
Código para o Header 
<script 
  src="https://trackeamento.hnperformancedigital.com.br/sdk/tracker.js"

</script>

Eventos Automáticos (Zero Código Adicional)

Assim que a tag é carregada, o SDK ativa 3 ouvintes globais para capturar os principais momentos da jornada do usuário sem que você precise escrever código JavaScript:

page_view

Visualização de Página

Disparado no carregamento da URL. Salva e preserva no localStorage todos os parâmetros de anúncio da URL (utm_source, utm_medium, utm_campaign, gclid, fbclid, etc.) em modelo First-Touch resiliente.

whatsapp_click

Cliques de WhatsApp

Intercepta automaticamente qualquer clique em links wa.me/*, api.whatsapp.com/* e whatsapp.com/*, gravando a URL do WhatsApp e o texto do botão clicado.

lead (Auto-Form)

Submissão de Formulários

Monitora envios de <form> na página, extrai e normaliza automaticamente campos de e-mail, telefone/celular e nome do lead, enviando via navigator.sendBeacon sem atrasar a navegação.

Disparos Manuais via JavaScript (window.hnTrack)

Para funis com modais JS, popups, botões customizados ou checkout de e-commerce, use a função global window.hnTrack(eventName, options):

Ideal para formulários via AJAX/Fetch, modais de captura, popups e formulários multi-etapas.

Deduplicação 100% Perfeita com Meta Pixel & CAPI

Para garantir que o Meta Ads não duplique conversões quando o cliente tiver o Meta Pixel do navegador e o nosso Tracking Server-side rodando juntos, a função window.hnTrack retorna automaticamente o event_id (UUID v4) gerado no navegador:

Exemplo de Deduplicação (Browser Pixel + HN Engine) 
// 1. Dispara no HN Tracker Engine e obtém o eventId único
var eventId = window.hnTrack('lead', {
  user_data: { email: 'lead@exemplo.com.br', phone: '5511999998888' }
});

// 2. Se o Meta Pixel tradicional estiver ativo na página, passe o mesmo eventID:
if (typeof fbq === 'function' && eventId) {
  fbq('track', 'Lead', {}, { eventID: eventId });
}

Passo 5: Envios Server-Side para LinkedIn Conversions API (Direct API)

O Trackeamento HN possui conector nativo para a LinkedIn Conversions API (Direct API), permitindo o encaminhamento de conversões qualificadas (como lead, purchase e contact) diretamente aos servidores do LinkedIn Marketing Solutions com sanitização e hashing SHA-256 em conformidade com as diretrizes oficiais (Help LMS #a1711116).

1. Gerar Access Token

No Campaign Manager, acesse Mensurar > Gerenciador de Sinais > Direct API e clique em Gerar token de acesso. Guarde o token com segurança pois ele não é exibido novamente.

2. Criar Regra de Conversão

Em Mensurar > Rastreamento de conversões, crie uma conversão via Conversions API, selecione o método Direct API, vincule aos Ad Sets desejados e copie o Conversion Rule ID.

3. Ativar e Testar no Dashboard

Abra o menu Envios & CAPI (Wizard) no dashboard do Trackeamento HN, selecione LinkedIn CAPI, preencha as credenciais e clique em Disparar Teste de Envio para validar a conexão.
